# Portafolio · Josué López Urbina

Portafolio personal hecho a mano con HTML, CSS y JavaScript puros (sin frameworks).

🌐 **En vivo:** https://putrefacto669.github.io

## Estructura
```
index.html      → contenido y estructura
css/styles.css  → estilos (tema oscuro "cuarto de noche", responsive)
js/main.js      → reloj en vivo con la hora de Masaya y botón para copiar el correo
```

## Correr localmente
Abre `index.html` en el navegador, o sirve la carpeta:
```
python3 -m http.server 8000
```
